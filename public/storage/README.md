# storage

Site images served at `/storage/...`.

- `tade-bg.jpg` or `tade-bg.png`: background of the About Me section. The section uses the `.jpg` if present, otherwise the `.png`. A wide landscape image (about 1920×1080) works best.
- `tade-profile.jpg` or `tade-profile.png`: profile photo in the header (top left). Used instead of the default profile picture when present. A square headshot (at least 200×200) works best.
